# 🌍 NearbyPlace — Tourism Planner

A simple, responsive web application that helps users discover nearby tourist
places. Browse temples, beaches, parks, museums, restaurants, and monuments —
all in one place.

## Features

- **Category Filtering** — Filter places by type (temples, beaches, parks, museums, restaurants, monuments).
- **Text Search** — Search places by name, description, or category.
- **Geolocation** — Use your browser's location to sort places by distance.
- **Responsive Design** — Works on desktop, tablet, and mobile screens.

## Getting Started

No build tools or dependencies are required. Simply open `index.html` in any
modern browser:

```bash
# Clone the repository
git clone https://github.com/Rohith-R777/nearbyplace.git
cd nearbyplace

# Open in your default browser
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

Or serve with any static file server:

```bash
npx serve .
```
